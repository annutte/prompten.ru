## 🌐 Сайт на Tilda   

- Описание услуг исполнителя. 
- Блок с кейсами, страница по каждому реализованному проекту.  
- Поиск по сайту, Политика конфеденциальности. 

---

## 🤖 ИИ-ассистент
- На сайт интегрировано окно чата с ИИ-ассистентом.  
- Нейроассистент консультирует по услугам и подводит клиента к заполнению формы заявки.
- Тот же ассистент подключён в Telegram. 

---

## ✏ Реализация
- Сайт на Tilda с использованием Zero Block.  
- Ассистент на базе OpenAI Assistant.  
- Бот реализован на Flask и обрабатывает 2 канала: сайт и Telegram.
- На Tilda используется встроенная форма сбора заявок, в Telegram – форма на Grist в виде Telegram mimi-App.  
- Оповещения о новом диалоге с ИИ и заполнении формы заявки отправляются в служебный чат в Telegram (через n8n).  
- Запись диалогов и заявок производится в базу данных Grist (развёрнута на сервере на территории РФ).
