## 🤖 ИИ-ассистент
- Виджет чата с ИИ-ассистентом  
- Нейроассистент консультирует по услугам и подводит клиента к заполнению формы заявки
- Тот же ассистент подключён в Telegram 

---

## ✏ Реализация
- Сайт на Tilda с использованием Zero Block, Потоков и Магазина с корзиной и оплатой
- Ассистент на базе OpenAI Responses API (до августа 2026 – OpenAI Assistant)  
- Бот на Flask (Docker контейнер на сервере), обрабатывает 2 канала: сайт и Telegram
- На Tilda используется встроенная форма сбора заявок, в Telegram – Grist форма в виде Telegram mimi-App (сбор данных на сервер в РФ по 152-ФЗ)  
- Оповещения о новом диалоге с ИИ и заполнении формы заявки отправляются в служебный чат в Telegram (через n8n)  
- Запись диалогов и заявок производится в базу данных Grist (развёрнута на сервере на территории РФ)
